## About

I build end to end products with TypeScript, from the database to the interface. Next.js and Fastify on the web, React Native and Expo on mobile, PostgreSQL and Prisma underneath.

Graduated in Systems Analysis and Development at UNOESTE. I care about typed code, automated tests, clear separation of concerns and documentation that someone else can actually follow. Every project below ships with its own README and a CI pipeline that runs on every push.

Currently building **Netsheet Engine** and evolving **Newra News**.

**Repertório Progressivo**

- Layered architecture: `AsyncStorage` to services, context, hooks and components
- 144 tests across 8 suites: 6 unit, 2 integration mounting the real providers
- Scheduled Android notifications through `expo-notifications`
- Runs fully offline: no account, no server, no network call
- Release builds with R8 minification, resource shrinking and AAB splitting by language, density and ABI
- 8 Mermaid architecture diagrams in `docs/architecture.md`

**Newra News**

- Turborepo monorepo with `apps/web` (Next.js) and `apps/api` (Fastify) on pnpm workspaces
- Hundreds of articles a day from NewsData.io and 12 RSS feeds, deduplicated into one daily briefing
- Google Gemini as the primary model, Groq as fallback; every briefing cites its sources and discloses that it was AI generated
- PostgreSQL on Neon with Prisma, migrations applied by a dedicated workflow rather than from a local machine
- 1,409 unit and integration tests plus 29 Playwright specs run against production
- Six GitHub Actions workflows: CI, Gitleaks, Smoke E2E, Lighthouse CI, Migrate and Keep-alive

**Trak Assessoria**

- Next.js 16 (App Router) with React 19, shadcn/ui and Base UI as accessibility primitives
- Contact form with React Hook Form and Zod, validated on the client and again on the server, delivered through Resend
- Dark mode persisted with next-themes, CSP declared in `next.config.ts`
- 132 unit and component tests across 33 files, 18 E2E specs on Chromium, Firefox, WebKit and a 375px viewport
- Coverage gated at 80% statements and 85% lines
- Technical SEO with JSON-LD, sitemap and Open Graph, plus LGPD consent

**Netsheet Engine**

- Sheet builder with stat calculator, cyberware, lifepath and the FNFF dice roller
- Real time multiplayer tables over WebSockets and Yjs, with tactical grid, initiative and GM powers
- Supabase for auth, PostgreSQL, realtime and storage; Express serving the SPA on a single port
- Netrunner assistant integrating the Gemini API
- Gitleaks secret scanning in CI, with custom rules and an optional pre-commit hook
